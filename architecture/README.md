# Architecture

Working layers:

```text
Environment / Reality
        ↓
Hierarchical Representations (A0 ... An)
        ↓
Candidate Activation ↔ Existing Circuit Recall
        ↓
Binding / Dynamic Routing
        ↓
Competition / Inhibition / Recurrence
        ↓
Convergence
   ├─ adequate → result → validation → compilation/reuse
   └─ mismatch → graph expansion → A/D/M adaptation
```

Two design principles inherited from the current hypothesis:

- **Configuration is slow.** Structural/plastic changes alter what circuits exist.
- **Execution is local.** Activation, propagation, inhibition, completion, and settling should be locally executable where possible.
