# Related Work

This directory should compare the hypothesis against established and current work without forcing equivalence.

Suggested comparison dimensions:

- predictive processing / predictive coding,
- attractor networks,
- recurrent neural networks,
- global workspace-style architectures,
- active inference,
- hierarchical Bayesian models,
- graph neural computation,
- neural program induction / modular reasoning,
- complementary learning systems,
- memory consolidation and skill compilation,
- neuromorphic / event-driven computing,
- binding and variable-binding mechanisms.

For each source, record:

1. what mechanism it actually proposes,
2. which HCC claim it overlaps with,
3. the exact difference,
4. whether it weakens novelty or supplies supporting prior art,
5. what experiment could distinguish them.
