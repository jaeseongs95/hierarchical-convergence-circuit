# Research Roadmap

## R0 — Repository foundation

- Freeze the initial integrated hypothesis source.
- Assign stable claim IDs.
- Separate observed evidence from hypotheses and derived predictions.
- Define experiment contracts before implementation.

## R1 — Minimal computational prototype

Goal: implement the smallest system capable of demonstrating:

1. candidate activation,
2. binding,
3. competition/inhibition,
4. recurrent convergence,
5. mismatch-triggered graph expansion,
6. repeated-success compression into a reusable path/circuit.

The first prototype should not attempt to model a biological brain.

## R2 — Controlled experiment suite

Prioritize:

1. EXP-01 Familiarity Compression,
2. EXP-02 Novelty-triggered Graph Expansion,
3. EXP-03 Misconvergence,
4. EXP-04 Binding Continuity.

## R3 — Cross-abstraction validation

Test whether the same computational primitive can operate on low-, middle-, and high-abstraction tasks while changing representation rather than core dynamics.

## R4 — Architecture expansion

Only after R1–R3 survive controlled tests:

- distributed routing,
- sparse/event-driven execution,
- structural plasticity,
- stronger local recurrence,
- neuromorphic mapping.

## R5 — External validation

- independent replication,
- ablation studies,
- comparison with alternative architectures,
- preprint/manuscript preparation,
- external datasets or neural evidence where justified.
