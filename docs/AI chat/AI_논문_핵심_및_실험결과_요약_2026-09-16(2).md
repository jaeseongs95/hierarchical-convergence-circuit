# A/D/M 기반 Thought-Graph 연구 핵심 및 실험결과 요약

작성 기준일: 2026-09-16

## 1. 논문의 핵심 내용

이 연구의 핵심 질문은 **같은 문제와 같은 목표를 유지한 상태에서 사고 경로의 구조를 바꾸면, LLM이 실제로 만들어내는 유효한 추론 구조와 성능이 달라지는가**이다.

이를 세 축으로 모델링한다.

- **A — Abstraction**: 문제와 추론을 표현하는 추상화 수준
- **D — Decomposition**: 최종 목표를 지지하는 추론 DAG의 의존 깊이
- **M — Modality / Method**: 추론·검토의 대상과 방법

현재 가장 깊게 검증한 축은 **D**이다.

여기서 D는 단순한 출력 길이, 토큰 수, 규칙 수, 응답 시간이나 모델 내부 hidden-state 깊이가 아니다.  
초기 사실을 깊이 0으로 두고, 각 규칙 결과의 깊이를 `1 + max(전제 노드 깊이)`로 계산한 **실제 proof graph의 의존 깊이**를 의미한다.

따라서 현재의 구체적인 연구 질문은 다음과 같다.

> 같은 문제·목표와 고정된 primitive inference system에서, 요구하는 추론 의존 깊이에 따라 실제 유효한 최종 proof graph의 D를 선택적으로 바꿀 수 있는가?

---

## 2. 실험에서 유지한 핵심 원칙

- 모델이 스스로 `D=5`, `deep`이라고 답한 것은 성공으로 인정하지 않는다.
- 실제 `facts → rules → parents → final → goal ancestry`를 다시 검사하여 D를 계산한다.
- 잘못된 ID, parent, premise 등을 사후에 보정하지 않는다.
- **선택 성공 / graph 생성 성공 / 요구 D 성공 / 양방향 성공**을 분리해서 측정한다.
- 독립 검산과 audit는 기존 응답의 검증이며 새로운 연구 표본으로 세지 않는다.

주요 실험 모델은 로컬 **Qwen3 4B Instruct**이다.

## 3. 주요 실험 결과

### 초기 실험: 표현과 실행 구조의 영향

v047~v050에서는 논리적으로 동등한 문제라도 **표현 순서와 실행 구조에 따라 성공률이 크게 달라질 수 있음**을 확인했다.

즉 초기의 단순한 설명인 “작은 모델이라 복합 논리를 못한다”보다는,

> **같은 논리라도 표현·실행 구성이 달라지면 모델의 성공 여부가 달라진다**

는 방향으로 원인 가설이 수정됐다.

### A×D×M 통합 pilot

v051에서 A/D/M을 한 번에 제어하려 했을 때 전체 성공은 **0/240**이었다.

하지만 실패를 분석하면 단순 정답 능력 하나의 문제가 아니라,

- 경로 선택
- 출력 형식
- proof graph 구성
- 검토 단계

가 서로 다른 실패 지점이었다.

이후 세 축을 한 번에 검증하기보다 **축별로 분리하여 검증**하는 방향으로 연구가 전환됐다.

### D 축 제어 — two-stage 방식

v083~v086에서는 외부에서 정확한 D 정보를 제공하고,

1. 목표 D에 맞는 값을 선택
2. 그 값을 실제 경로 ID에 연결
3. 선택된 경로로 proof graph 생성

을 분리했다.

v085에서는:

- 경로 선택: **128/128**
- 실제 요구 D 종단: **124/128**
- shallow/deep 양방향 성공: **60/64**

까지 상승했다.

새 구조 U01~U08로 옮긴 v086에서도:

- 경로 선택: **128/128**
- 실제 요구 D 종단: **115/128**
- 양방향 성공: **51/64**
- D=5 경로: **16/16 성공**

이 관찰에서는 **깊이가 커질수록 단순히 실패가 증가하는 패턴은 나타나지 않았다.**

### v087 — ID 연속성 문제 발견

현재 생성할 노드에 새로운 ID를 강제로 지정하는 방식은 오히려 성능을 크게 낮췄다.

- baseline 실제 D 종단: **113/128**
- 새 ID 지정군: **32/128**
- ID+inventory 결합군: **43/128**

양방향 성공도 baseline **49/64**에서 결합군 **13/64**로 떨어졌다.

중요한 점은 모델이 지정된 현재 ID 자체는 **1,400/1,400** 정확하게 사용했다는 것이다.

실패는 이후 규칙에서 그 ID를 다시 parent로 참조하는 과정에서 발생했다.

즉,

> **ID를 정확히 생성하는 능력과, 생성한 ID를 다음 추론 단계에서 정확히 재참조하는 능력은 별개의 문제**

라는 것이 확인됐다.

### v089 — ID 표현 4×4 교차 실험

동일한 의미 구조에서 ID 표현을 교차시킨 결과:

- `atom_alias → atom_alias`: **29/32**
- `atom_tagged → atom_tagged`: **28/32**
- `atom_alias → long`: **0/32**

등 큰 차이가 나타났다.

사전 정의한 주평가 효과는 **+34.375%p**였다.

즉 단순히 “짧은 ID가 좋다 / 긴 ID가 나쁘다”가 아니라,

> **초기 노드와 후속 노드 사이에서 원자 의미와 ID가 어떤 방식으로 대응되고 일관되게 유지되는가**

가 연속 graph 생성 성능에 중요하다는 결과가 나왔다.

### v090 — 새 선택·새 facts부터 전체 종단 검증

v089에서 발견한 의미 기반 ID 효과를, 기존 정답 history가 아니라 **새로운 선택 → 새 facts → 전체 규칙 → final**까지 포함한 종단 실험으로 확장했다.

| 생성 조건 | 엄격 D 종단 | 양방향 D 종단 |
|---|---:|---:|
| baseline | 106/128 | 43/64 |
| short_uniform | 75/128 | 18/64 |
| atom_alias | **121/128** | **57/64** |
| atom_tagged | 116/128 | 56/64 |

사전 주평가인 `atom_alias - baseline`의 양방향 차이는:

> **+21.875%p**

였다.

모든 군에서 facts 생성과 ID 계약 자체는 정상적으로 수행됐으며, 최종 차이는 주로 **후속 규칙에서 올바른 직접 전제를 parent로 연결하는 단계**에서 발생했다.

따라서 이 실험에서는 의미를 드러내는 ID 표현이 단순한 ID 지정 지원보다 실제 연속 proof graph 생성에 유리하게 작동했다.

다만 효과는 구조별로 동일하지 않았으며 일부 구조에서는 여전히 전제 누락이나 잘못된 parent 선택이 남았다.

## 4. 현재까지의 연구 결론

현재까지 가장 강하게 지지되는 내용은 다음과 같다.

1. **LLM의 추론 결과는 논리 문제 자체뿐 아니라 표현·경로·인터페이스 구조에 민감하다.**
2. D를 직접 말로 지시하는 것보다 **선택과 실행을 구조적으로 분리했을 때 실제 proof graph의 깊이를 훨씬 안정적으로 제어할 수 있다.**
3. 경로를 올바르게 선택하는 것과 그 경로를 실제 graph로 생성하는 것은 별개의 문제다.
4. graph 생성에서는 **노드 식별자와 의미 사이의 대응 및 연속 참조 구조**가 중요한 변수로 관찰됐다.
5. 의미 기반 ID는 현재 실험 환경에서 baseline보다 높은 D 종단 성능을 보였다.

현재 결과는 **D 축이 실제 외부 proof graph 수준에서 제어 가능한가**라는 질문에는 상당한 실험적 근거를 제공한다.

하지만 아직 다음은 별도 검증이 필요하다.

- 외부 D 정보 없이 모델이 스스로 D를 안정적으로 계산·선택할 수 있는가
- A와 M 축도 독립적으로 같은 수준까지 제어 가능한가
- A/D/M을 결합했을 때 축별 효과가 유지되는가
- 새로운 모델·문제·완전 신규 구조에서도 결과가 재현되는가
- 관찰된 현상이 모델 내부에서 어떤 메커니즘으로 발생하는가

---

## 5. 한 줄 요약

> **이 연구는 LLM의 사고를 A/D/M 축의 그래프로 모델링하고 있으며, 현재 D 축 실험에서는 단순 프롬프트 지시보다 경로 선택·표현·ID 연속성을 구조적으로 설계했을 때 실제 추론 DAG의 깊이와 성공률을 선택적으로 제어할 수 있다는 증거가 축적되고 있다.**
