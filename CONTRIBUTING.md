# Contributing

This repository is currently organized as a hypothesis-driven research program.

## Before proposing a change

Classify the change as one of:

- theory clarification,
- new claim,
- evidence update,
- experiment design,
- implementation,
- replication,
- related-work comparison.

## Claims

A new substantive claim should include:

- a stable claim ID,
- exact statement,
- current status,
- falsification condition,
- supporting/conflicting evidence,
- linked experiment(s).

Do not silently promote a hypothesis to an observed result.

## Experiments

Every experiment should freeze, before execution:

- research question,
- hypothesis and null/alternative where applicable,
- independent/dependent variables,
- controls,
- success/failure criteria,
- randomization/seeds,
- stopping rule,
- artifact schema,
- analysis plan.

## Theory changes

Do not rewrite historical source documents in `theory/source/`. Add a new version or update derived documents while preserving provenance.
