# Candidate Invariants

These are provisional properties to test or refine, not established laws.

1. **A/D distinction** — changing representation level must not be treated as equivalent to increasing dependency depth.
2. **Binding continuity** — a graph edge is valid only if meaning/identity/parent relation remain consistent across transitions.
3. **Convergence is not correctness** — a stable state can still disagree with external reality.
4. **Observed D is not necessarily effective internal D** — a system may reconstruct an explicit path after compressed execution.
5. **Compression must preserve validation criteria** — faster reuse is not successful learning if external correctness degrades beyond the frozen threshold.
