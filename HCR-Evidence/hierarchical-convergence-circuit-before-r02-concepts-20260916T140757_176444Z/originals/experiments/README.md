# 실험과 개발 검증

현재 실행 가능한 것은 `exp-00-r01-integration/design.md`의 개발 fixture다. 이는 공학적 연결 검증이며 가설 효과를 추정하는 사전등록 benchmark가 아니다. 설정을 고정한 뒤 별도 독립 입력으로 수행할 연구는 EXP-01~07에서 계속 설계한다.
