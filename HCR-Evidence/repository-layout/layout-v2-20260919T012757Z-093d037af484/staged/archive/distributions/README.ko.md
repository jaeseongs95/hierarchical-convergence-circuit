# 과거 배포파일 보관

루트에 누적된 내장 ZIP 원클릭 설치기/핫픽스 중 현재 소스·manifest·상대 링크에서 참조하지 않는 항목만 옮긴다. 파일 바이트는 보존한다.

이곳의 설치기를 현재 저장소에서 직접 실행하지 않는다. 과거 설치기는 당시 루트 배치를 전제로 한다. 역사 재현은 당시 commit의 별도 checkout에서 당시 배치/계약을 따라야 한다. 이미 설치된 코드는 루트 `Run-HCR.cmd`로 실행한다.

[이동/보류/기존 문서 언급 목록](INDEX.json)에 원래 경로와 새 경로, SHA-256이 기록된다. 과거 문서의 원클릭 파일명 언급은 당시 배치 기록으로 보존되며 현재 실행 안내가 아니다.
