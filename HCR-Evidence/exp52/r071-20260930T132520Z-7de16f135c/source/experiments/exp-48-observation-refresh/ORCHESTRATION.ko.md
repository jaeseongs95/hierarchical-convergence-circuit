# R067 작업 연결

orchestrator registry의 활성 provider priority는 모두 50이다. 지침 경로가 확인되어 instruction-scope-resolution(10), 후속 요청을 검증 가능한 범위로 정하기 위해 task-contract-definition(30), 기존 untracked 보호를 위해 change-scope-baseline-capture(42)를 선택했다. 새 실험 코드에는 minimal-implementation(44), 구현 완료 뒤 change-scope-assurance(60)와 acceptance-evidence-validation(70)을 연결한다. 각 provider의 selectionCriteria와 precondition을 현재 작업에 대조했다.

같은 프로젝트 지침 hash를 확인하고 기존 실행 관례와 R066 NEXT를 읽었다. 계약과 기준선은 구현 전에 동결했다. 전문 스킬을 직접 호출하는 흐름이며 MCP guarded workflow 완료로 표현하지 않는다. 새 controller·측정·검산 모듈만 작성하고 native engine과 과거 evidence는 보존한다. 별도 로직·프로세스 검산은 독립 연구자 감사가 아니다.

범위·수용 기준 확인 뒤 Git 전달 전에 세션 현황판, 정확한 staged 범위, 원격 main 및 사용자 메시지에 명시된 일반 push 권한을 확인한다. baseline에 포함된 계약 작성 파일은 준비 artifact로 별도 구분하고 바이트를 보존한다. 한국어 보고는 연구 결과 작성이며 별도의 문체 편집 작업으로 확장하지 않는다.
