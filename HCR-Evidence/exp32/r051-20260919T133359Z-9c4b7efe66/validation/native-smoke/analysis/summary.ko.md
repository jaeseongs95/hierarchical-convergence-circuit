# EXP-32 / R051

실행 목적: implementation_validation

독립 원자료 검산을 통과했다. 검산 통과는 가설 지지를 뜻하지 않는다.

| 강도 | top-down | 개입 | 채택 | 정답 채택 | 오답 채택 | 보류 | 추가 ticks |
|---|---|---|---:|---:|---:|---:|---:|
| 0.02 | False | hold | 0 | 0 | 0 | 1 | 0 |
| 0.02 | False | revision_only | 0 | 0 | 0 | 1 | 37 |
| 0.02 | False | edge0 | 1 | 1 | 0 | 0 | 47 |
| 0.02 | False | edge1 | 1 | 1 | 0 | 0 | 44 |
| 0.02 | True | hold | 0 | 0 | 0 | 1 | 0 |
| 0.02 | True | revision_only | 0 | 0 | 0 | 1 | 88 |
| 0.02 | True | edge0 | 0 | 0 | 0 | 1 | 60 |
| 0.02 | True | edge1 | 0 | 0 | 0 | 1 | 116 |

동일 기준선의 분기는 독립 표본이 아니다. 관측 강도 조작은 센서 측정이 아니다.
edge0와 edge1은 변경 edge 수와 총 강도 증가를 맞춘 위치 대조다.
부호 충돌 감소, proof 유효성, 채택을 별도로 해석한다. 구현 검증은 연구 결과로 합산하지 않는다.
