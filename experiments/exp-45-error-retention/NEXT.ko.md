# R064 이후 판별 질문

다음 순서는 **현재 기억 표현이 어떤 교정 정보를 보존할 수 있는지 확인하는 것**이다. R063의 회로 형성·재사용과 R064의 오류 feedback·재개는 관찰됐지만, “교정 경험이 남아 같은 잘못된 관측을 이긴다”는 연결은 성립하지 않았다.

R064의 강도 약화는 실제로 일어났다. 그러나 before/after_feedback/after_correction 모두 잘못된 양성 관측에서는 ON/OFF가 함께 틀렸다. 올바른 음성 관측에서는 before부터 맞았다. 교정 뒤 learner의 changes는 비어 있었다. 그러므로 회로가 약해지는 횟수만 늘리는 것을 교정 기억의 검증으로 취급하지 않는다.

다음 작업의 최소 범위는 다음과 같다.

1. source와 R064 raw에서 observation → feedback → patch → 저장 memory → 다음 판단의 정보 흐름을 직접 대조한다. audit용 이력에 존재하는 값과 다음 추론이 실제 사용하는 값을 구별한다.
2. 동일 public observation·동일 memory에 대해 실제 세계만 열린 경우와 닫힌 경우로 나눈 참조 대조를 사전 고정한다. 동일 native packet의 재평가임을 표시하며, 새 실행·독립 표본으로 세지 않는다. 추가 정보가 없을 때 양쪽 세계를 모두 맞힐 수 있는지 논리적으로 검산한다.
3. 올바른 False proof 뒤 보존된 것이 절차적 회로, 상황별 사실, 단순 feedback 이력 중 무엇인지 판정한다. “구조 재사용 유지”와 “세계 사실 교정 유지”를 서로 다른 수용 기준으로 작성한다.
4. 기존 표현으로 다음 판단에 전달할 수 없는 정보가 확인되면 그 한계를 결과로 남긴다. 새로운 memory 기능을 같은 실험에 몰래 넣지 않는다. 이후 구현 후보가 필요하면 명시적 사실 기록을 이용하는 단순 baseline부터 별도 계약·독립 검산·정보량 통제를 설계한다.

이 문서는 다음 턴의 조사 방향이며 아직 새 실험의 frozen contract가 아니다. 다음 턴은 표현과 판정 기준을 먼저 확정하고, 새 native 실행이 추가 정보를 제공하지 않으면 실행 횟수를 늘리지 않는다. HCC 전체를 옹호하거나 반증하는 방향으로 기준을 조정하지 않는다.
