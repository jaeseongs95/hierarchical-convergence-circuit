R034~R047의 원 manifest도 같은 `archive/releases/rNNN/` 아래에 보존한다.
기존 source_commit과 run_status는 이번 정리로 새 판정하거나 덮어쓰지 않는다.

EXP-43의 독립 실행은 [Run-HCR-R062.cmd](../Run-HCR-R062.cmd), 설계는 [native feedback](exp-43-native-feedback/design.ko.md)을 따른다. 현재 전체 목록은 INDEX.json이며 공통 기본 실행은 EXP-30을 유지한다.

EXP-44의 독립 실행은 [Run-HCR-R063.cmd](../Run-HCR-R063.cmd), 설계는 [회로 형성 전후](exp-44-circuit-formation/design.ko.md)를 따른다.

EXP-45 / R064: [오류 교정·재노출 유지](exp-45-error-retention/design.ko.md). 독립 진입점 `Run-HCR-R064.cmd`; 기본 dispatcher는 그대로 유지한다.

EXP-46 / R065: [기억 정보 경계 재분석](exp-46-information-boundary/design.ko.md). `Run-HCR-R065.cmd`; 기존 R064 packet 재채점이며 새 native 연구 실행은 없다.

EXP-47 / R066: [명시적 사실 저장·조회 baseline](exp-47-fact-retrieval/design.ko.md). `Run-HCR-R066.cmd`; context/epoch 경계와 미통지 변화에서 입력 개입 효과를 비교한다.

EXP-48 / R067: [충돌 뒤 추가 관측 정보 효과](exp-48-observation-refresh/design.ko.md). `Run-HCR-R067.cmd`; e0 고정, 과거 사실·stale·fresh e1과 회로 ON/OFF를 비교한다.

EXP-49 / R068: [native 관측 요청 경계](exp-49-request-boundary/design.ko.md). `Run-HCR-R068.cmd`; 외부 오답 피드백 없는 요청과 별도 합성 revision 검사를 구분한다.

EXP-50의 독립 실행은 [Run-HCR-R069.cmd](../Run-HCR-R069.cmd), 설계는 [revision factorization](exp-50-revision-factorization/design.ko.md)을 따른다. 기본 dispatcher는 변경하지 않는다.

EXP-51 / R070: [회로 약화 신호의 전달 경계](exp-51-pool-signal-boundary/design.ko.md). `Run-HCR-R070.cmd`; R069 네 packet 재분석이며 새 native 연구 실행과 독립 표본은 없다.

EXP-52 / R071: [native 선택 경계](exp-52-native-selection-boundary/design.ko.md). `Run-HCR-R071.cmd`; config별 native 형성·약화 뒤 네 paired 평가. 최초 분석 실패 보존, native 재실행 없이 분석 복구.
EXP-53 / R072: [고정 선택 경계의 입력 범위](exp-53-selection-input-range/design.ko.md). `Run-HCR-R072.cmd`; 봉인된 R071 memory에서 세 score의 12개 native 평가, 0.8 네 셀은 기존 조건 반복. 선택·판단·정수 비용을 분리한다.
