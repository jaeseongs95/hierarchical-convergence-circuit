# 실행 전 결과별 판단

| 관측 | 판단 |
|---|---|
| 전체 정확동치·품질·원장·복원 PASS, 모든3반복 부담<=10%, 같은 최대범주>=30% | 유한 경로의 coarse 후속 조사 후보만 부여 |
| 해당 arm 부담 초과 | 비계측 병목 순위/우선 후보 보류, 기술적 관측만 공개 |
| 최대범주 또는30%조건 불안정 | 단일 조사 우선 후보 없음 |
| 이력·판단·출처·복원·원장 불일치 | 비용 해석 금지, 첫 불일치와 완료 자료 보존 |
| 상한 중단·원자료 부족 | 판정 불가 범위 명시, 동일 native 재실행 금지 |

R41 음성 결과를 바꾸지 않는다. R40의 비용 채택 기준도 바꾸지 않는다. 계측 통과는 최적화 효과나 제품 채택을 뜻하지 않는다.
