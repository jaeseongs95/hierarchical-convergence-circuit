# R065 작업 연결

orchestrator registry에서 instruction-scope-resolution, workspace-convention-profiling, task-contract-definition을 bootstrap으로 선택했다. 작업은 경로 지침이 있는 낯선 저장소의 후속 연구이고 현재 source와 완료 근거가 필요하다. 모두 priority 50이며 각각 경로·읽기 권한·사용자 요청의 precondition을 확인했다.

workflow는 change-scope-baseline-capture(42) → minimal-implementation(44) → change-scope-assurance(60) → acceptance-evidence-validation(70)의 직접 전문 스킬·로컬 CLI로 수행한다. 모든 provider는 priority 50이며 mutation-workflow, code-writing-step, implementation-change-present, completion-claim-needs-evidence에 해당한다. baseline은 첫 저장소 변경 전에 동결했다. Git 전달 직전에는 별도로 정확한 target과 사용자 승인 범위·원격 상태를 확인한다.

MCP guarded workflow나 독립 연구자 감사를 실행했다고 주장하지 않는다. 이 작업은 기존 원자료의 제한된 로컬 재분석이며 subagent·모델 변경·새 memory 기능이 없다. 연구 보고를 별도의 산문 스타일 편집 작업으로 확장하지 않는다. 산출물은 이번 분석 도구·계약·결과·색인과 신규 evidence 폴더로 한정한다.
