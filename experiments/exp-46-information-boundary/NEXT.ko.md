# R065 이후: 사실 정보의 저장과 조회를 분리하는 baseline

다음 최소 과제는 **명시적 사실 기록이 다음 판단을 바꿀 수 있는지, 그리고 그 효과가 추가 정보량 때문인지**를 분리하는 것이다. 이번 source와 기존 packet의 재분석만으로 사실 memory의 효과를 측정했다고 할 수 없다.

후속 계약은 다음 순서로 작성한다. 아직 동결된 실행 계약이나 구현 승인이 필요한 별도 기능의 완성본은 아니다.

1. 과제의 세계·상황 ID, 관측 시점 또는 epoch, edge identity와 사실의 유효 범위를 먼저 정의한다. 같은 edge ID나 episode ID만으로 모든 세계의 동일 사실로 취급하지 않는다. 기존 API에 없는 구분값을 host가 몰래 제공하지 않는다.
2. 첫 baseline은 신뢰할 수 있는 요청 교정 관측을 `(context, epoch, edge_id, value, provenance)` 형태로 저장하고 범위가 일치할 때 조회하는 단순 표로 한정한다. binary correctness만 받은 조건과 edge별 교정 관측을 받은 조건은 별도로 둔다. 정답에서 닫힌 edge를 임의로 추측하지 않는다.
3. 동일 교정 정보를 받은 군들에서 현재 memory / 기록만 하고 미조회 / 명시적 기록·조회 baseline을 비교한다. 기록·미조회 군이 필요 없는 경우에는 그 이유를 사전에 정한다. 유효 정보 bit, 저장량, 조회 비용, 관측 접근 횟수를 기록한다. 회로 ON/OFF는 별도 통제다.
4. native 관측을 사실표로 덮어쓰면 **명시적 입력 개입**으로 표시한다. host correction을 native 능력으로 합산하지 않는다. 원래 관측, 조회 결과, 실제 입력, 최초 판단, proof/readout을 모두 보존한다.
5. 먼저 고정 세계에서 동일 상황 재노출을 검사하고, 이어 context 불일치와 사실이 낡은 경우를 사전 고정한다. 외부에 알리지 않은 세계 변화는 어떤 memory도 자동 식별한다고 가정하지 않는다. unknown/충돌/채택 거부를 올바른 False와 구분한다.
6. 구조 재사용의 이득, 정보 저장·조회로 인한 교정 유지, 추가 관측의 이득을 각각 판정한다. 단순 사실표가 성공하면 “그 정보 경로로 해당 toy 과제를 해결할 수 있다”까지만 말한다. 그것만으로 Circuit 학습, 일반화 또는 HCC의 독자적 우위를 주장하지 않는다.

한 번에 HCC 전체 memory를 확장하지 않는다. 먼저 작은 baseline과 별도 참조 검산으로 필요한 정보 경로가 실제로 작동하는지 확인한 뒤 다음 결합 실험을 결정한다.
