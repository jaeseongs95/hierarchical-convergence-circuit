# R066 작업 연결

orchestrator registry에서 bootstrap instruction-scope-resolution(10), workspace-convention-profiling(20), task-contract-definition(30)을 선택했다. 이어 change-scope-baseline-capture(42), minimal-implementation(44), change-scope-assurance(60), acceptance-evidence-validation(70)을 직접 전문 스킬·로컬 CLI로 연결한다. 각 provider priority는 50이며 경로 지침, 낯선 저장소, 후속 요청의 계약, 첫 변경 전 기준선, 코드 작성 및 완료 근거라는 selectionCriteria/precondition을 확인했다.

baseline과 task contract는 첫 구현 전에 고정했다. 기존 core와 과거 evidence는 읽기만 한다. 독립성은 생산 코드와 분리된 로직·프로세스의 검산이며 독립 연구자 감사나 MCP guarded workflow 완료로 표현하지 않는다. 코드 변경은 표의 저장·조회 baseline과 기존 실행·검산 경로의 연결로 한정한다. 한국어 결과 작성은 이번 연구 기록이며 별도 문체 편집 작업으로 확장하지 않는다. Git 전달 전에 세션 현황판과 실제 staged 범위, 원격 main 및 일반 push 권한을 다시 확인한다.
