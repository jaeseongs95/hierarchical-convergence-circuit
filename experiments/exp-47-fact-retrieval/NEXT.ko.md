# R066 이후: 충돌 뒤 추가 관측의 정보 효과를 분리한다

다음 최소 과제는 **과거 사실과 현재 관측이 충돌할 때 같은 추가 관측 예산으로 두 세계를 구별할 수 있는가**다. R066의 same/silent_change는 노출 정보가 같으므로 어느 쪽을 신뢰할지 현재 정보만으로 보장할 수 없었다. 이를 학습 횟수나 더 복잡한 회로로 해결했다고 주장하지 않는다.

후속 계약을 먼저 동결한다.

1. 같은 scope·과거 사실·원래 관측·native memory·config를 가진 closed/open 두 세계를 사용한다. 현재 관측의 +0.8과 과거 e1=False의 불일치는 두 세계 모두에서 발생한다. conflict 자체가 실제 세계 변화를 알려준다고 가정하지 않는다.
2. 과거 사실만 사용 / 같은 오래된 관측 재제공 / 신뢰할 수 있는 현재 e1 관측의 세 군을 분리한다. 추가 관측 한 번이라는 예산과 요청 edge e1을 먼저 고정하고, 실제 요청이 native 경로인지 명시적 baseline controller인지 표시한다. private truth를 판단 코드에 넘기지 않는다.
3. 먼저 e0 score와 모든 비조작 입력을 고정한다. R066에서 e0·e1 score가 함께 바뀐 한계를 제거하고 e1 정보의 기여를 검사한다. 관측의 새로운 유효 시점과 provenance를 기록한다.
4. 입력을 교체하기 전의 최초 판단과 추가 관측 뒤 판단·proof·adoption을 각각 보존한다. False, unknown, conflict, 거부를 구분한다. 새 사실 저장 효과와 이번 판단의 교정 효과도 분리한다.
5. 정확도와 추가 관측 횟수·조회 비용·native tick·expansion을 따로 비교한다. 같은 추가 정보를 직접 입력받는 단순 baseline을 둔다. 사실표가 성공해도 HCC의 고유 이점으로 올리지 않는다.

이 문서는 다음 판별 실험의 방향이며 아직 실행 결과가 아니다. native memory schema나 학습 규칙 전체를 확장하기 전에 필요한 정보 경로와 실패 경계를 먼저 확인한다.
