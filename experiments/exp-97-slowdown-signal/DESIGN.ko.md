# R51 / EXP-97 설계: 수렴 지연은 "이 판단이 회로 prior에 달려 있다"는 신호가 되는가 — 보류 gate의 표적 적중과 재사용 보존

작성 2026-11-20. 이 문서와 [frozen_spec.json](frozen_spec.json)은 본 실행 전에 작성했고 실행 뒤에는 수정하지 않는다. 번호 R51 / EXP-97은 잠정이다.

## 1. 출발점

[R50 / EXP-96](../exp-96-strength-capture/RESULTS.ko.md)의 사후 관찰: `legacy` 정책에서 회로가 약한 반대 증거를 누르고 True로 수렴하는 경계 근처 입력은 kernel tick이 65 수준에서 170~260으로 늘었다. 동기 문서(`docs/AI chat/계층적_수렴_회로_통합가설…` 12·21절)는 "낮은 수렴 여유·불일치"를 회로를 다시 그래프로 푸는 신호 후보로 들었다. R50은 이 관찰을 신호로 쓰지 않았고 4개 memory에서 본 것일 뿐이다.

이번 사이클은 그 관찰을 **보지 않은 조건에서 시험**한다: tick이 큰 판단에서 회로 사용을 보류하면(회로 OFF 결과를 채택하면) 회로 때문에 바뀐 판단이 걸러지고, 회로와 무관한 정상 재사용은 남는가.

## 2. 실행 전에 분명히 해 두는 한계

1. **내부 신호는 세계를 구별하지 못한다.** kernel의 동역학은 공개 관측과 memory에만 의존한다. 같은 관측에서 둘째 edge가 실제로 열려 있든 닫혀 있든 tick은 같다. 따라서 어떤 내부 신호도 "틀린 판단"을 직접 가려낼 수 없다. 가려낼 수 있는 것은 **"회로를 끄면 판단이 달라지는 입력"**(prior 의존 판단)뿐이다. 이번 실험의 표적은 그것이다.
2. **보류는 영합(zero-sum)일 수 있다.** prior 의존 판단에서 회로를 끄면, 닫힌 세계에서는 포획 오답이 사라지고 열린 세계에서는 올바른 보완(증거가 약해도 맞는 True)이 사라진다. 어느 쪽이 이득인지는 환경의 기저율에 달려 있고 이번 실험은 그것을 가정하지 않는다. 두 세계의 건수를 모두 보고한다.
3. **값싼 대안이 있다.** "묶인 edge 중 증거가 0 이하인 것이 있으면 보류" 같은 입력 기반 규칙은 추가 계산 없이 쓸 수 있다. R50의 e0 = 1.0 조건에서는 이 규칙이 표적과 정확히 일치한다(OFF는 e1 > 0에서만 True). tick 신호가 가치가 있으려면 이런 규칙이 못 잡는 조건에서 더 잘 잡아야 한다. 그래서 시험 조건에 **e0도 약한 입력**을 넣는다. 거기서는 모든 증거가 양수여도 OFF가 False일 수 있다.

## 3. 정의

- 실행 단위(셀): (memory, e0, e1). `legacy`, `FROZEN_EVAL`, 2-edge chain, `AdaptiveConfig()` 기본값. 엔진 수정 0.
- **적용 대상 셀**: 회로 ON 실행에서 회로가 실제로 선택된 셀. 선택되지 않은 셀에는 보류할 것이 없다.
- **표적 D**: 적용 대상 셀 중 ON의 채택값이 같은 (e0, e1)의 OFF 채택값과 다른 셀. 유형을 나눠 센다: 포획형(ON True, OFF True 아님), 미결정형(ON None), 기타.
- **보류**: 신호가 문턱 이상이면 그 셀의 최종 판단으로 OFF 결과를 채택한다. 새 정보(측정)는 받지 않는다.
- **재사용 보존율**: 표적이 아닌 적용 대상 셀 중 보류되지 않은 비율.

## 4. 비교할 신호 (모두 ON 실행 한 번에서 얻는 스칼라, 클수록 의심)

| 이름 | 정의 | 얻는 시점 |
|---|---|---|
| `ticks_total` | pool + decision network의 kernel tick 합 | 판단 뒤 |
| `ticks_pool` | pool network tick | 회로 적용 전 |
| `ticks_decision` | decision network tick | 판단 뒤 |
| `goal_margin` | −\|2·goal − 1\| (최종 goal의 낮은 여유) | 판단 뒤 |
| `pool_margin` | −\|2·activation − 1\| (선택 회로) | 회로 적용 전 |
| `uncertainty` | 묶인 edge의 max(1 − \|score\|) | 입력만 |
| `min_score` | −min(묶인 edge score) | 입력만 |
| `prior` | 엔진이 계산한 prior drive | 입력 + memory |

뒤의 세 개는 tick과 비교하기 위한 값싼 기준선이다.

## 5. 보정 집합과 시험 집합

- **보정(calibration)**: R50에서 이미 본 조건. native memory n ∈ {3, 4, 5, 6, 9, 12, 20} × e0 = 1.0 × e1 ∈ {−1.0, …, 1.0}(0.1 간격). 여기서 신호별 문턱을 정한다.
- **시험(test), 보정에 없던 조건**:
  - T-a 새 입력: n ∈ {3, 6, 9, 20} × e0 ∈ {0.2, 0.4, 0.6, 0.8} × e1 ∈ {−0.5, …, 1.0}(0.1 간격, 16점)
  - T-b 새 강도 + 새 입력: n ∈ {8, 15} × 위와 같은 64점
  - T-c 새 강도 + 옛 입력: n ∈ {8, 15} × e0 = 1.0 × e1 21점
- memory는 R50과 같은 방식(진실한 양수 chain 20개를 `legacy`·`TRAIN`으로 학습, 중간 snapshot)으로 만든다. n = 3…20의 문서는 R50의 것과 같아야 한다.
- **문턱 규칙(고정)**: 신호 S의 문턱 θ_S = 보정 집합의 표적 D 셀에서 S의 최솟값. 즉 보정 집합에서 재현율 100%가 되는 가장 엄격한 문턱. 시험 집합에서는 이 θ_S를 그대로 쓴다.

## 6. 측정

신호별로, 시험 집합 전체와 T-a/T-b/T-c 각각에 대해:

1. **AUC**: 표적 셀 하나와 비표적 적용 대상 셀 하나를 뽑았을 때 표적의 신호가 더 클 확률(동률 0.5). 문턱과 무관한 주 지표.
2. 고정 문턱에서의 **재현율**(표적 중 보류된 비율)과 **재사용 보존율**.
3. 닫힌 세계(e1 닫힘) 기준 포획 오답 수의 보류 전·후, 열린 세계(e1 열림) 기준 사라진 올바른 True 수. e0의 hidden 상태는 두 세계 모두 열림으로 둔다.
4. 비용: always-ON, always-OFF, 각 gate 정책의 kernel tick 합과 expansion 합. gate 정책은 보류한 셀에서 ON 실행과 OFF 실행을 모두 지불한다.

## 7. 사전 예측

- **P1 (신호 존재)**: 시험 집합 전체에서 `ticks_total`의 AUC ≥ 0.80.
- **P2 (문턱 이전)**: 보정에서 정한 `ticks_total` 문턱은 T-c(e0 = 1.0, 새 강도)에서 재현율 ≥ 0.9, 재사용 보존율 ≥ 0.8을 유지한다.
- **P3 (약한 e0에서 절대 문턱은 무너진다)**: T-a + T-b(e0 < 1)에서 같은 문턱의 `ticks_total`은 재현율 < 0.9 이거나 재사용 보존율 < 0.5다. 증거가 약하면 회로와 무관하게 수렴이 느려져 절대 tick 문턱이 구별력을 잃을 것이라는 예상이다.
- **P4 (입력 기준선과의 비교)**: T-c에서는 `min_score`가 AUC 1.0(±동률)로 tick 이상이다. T-a + T-b에서는 `min_score`의 AUC가 0.9 미만으로 떨어진다(모든 증거가 양수인 표적이 생기므로).
- **P5 (어떤 신호가 가장 나은가)**: 작성자의 추측은 `goal_margin` 또는 `ticks_decision`이 시험 전체 AUC 1위다. 확신은 낮다. 틀리면 그대로 보고한다.
- **P6 (영합)**: 보류로 제거된 닫힌 세계 포획 오답 수와, 같은 보류로 사라진 열린 세계 올바른 True 수는 같다(둘 다 "ON True, OFF True 아님" 셀이므로 정의상 같아야 한다. 다르면 집계 오류다).

## 8. 판정 규칙

| 결과 | 해석 |
|---|---|
| P1 supported이고, 시험 전체에서 `ticks_total`의 AUC가 세 입력 기준선(`uncertainty`, `min_score`, `prior`) 모두보다 0.05 이상 큼 | `SLOWDOWN_ADDS_INFORMATION`: 수렴 지연은 값싼 입력 규칙이 못 잡는 prior 의존 판단을 잡는다. 다음 단계(측정 요청과 연결)의 근거. |
| P1 supported이나 위 차이가 0.05 미만이거나 기준선이 더 나음 | `SLOWDOWN_REDUNDANT_HERE`: 신호는 있으나 이 과제에서는 입력만으로 얻을 수 있는 정보를 넘지 않는다. |
| P1 falsified | `SLOWDOWN_NOT_A_SIGNAL`: R50의 사후 관찰은 보지 않은 조건으로 일반화되지 않았다. |

tick 계열 중 `ticks_total` 하나를 주 신호로 고정한다(R50에서 관찰한 양). 다른 신호의 순위는 기술한다. 결과를 본 뒤 문턱 규칙·집합·주 신호를 바꾸지 않는다.

## 9. 예산과 경계

- 학습 20 episode. ON 평가: 보정 147 + 시험 426 = 573. OFF 평가: (e0, e1) 조합 85개(e0 = 1.0의 21 + 약한 e0의 64). 합계 658. worker 1, retry 0, 본 실행 1회, 결정성 재실행 1회. `World.measure` 0, revision 요청 0, feedback은 학습 20회뿐.
- 실행 전 허용한 엔진 접촉: trace에서 network별 tick을 읽는 방법을 확인하는 호출 1회(진실한 양수 chain, 빈 memory)와 `--smoke`(학습 3 episode).
- 2-edge chain, 길이 2 회로 하나의 결정적 비교이며 독립 표본이 아니다. AUC는 이 유한 격자에서의 순위 통계이지 모집단 추정이 아니다.
- tick 수와 이산 판정은 R50에서 두 호스트 사이에 같았으나(부동소수 마지막 자리만 차이), margin 계열 신호의 문턱과 동률 처리는 호스트에 따라 달라질 수 있다. 검산은 이산 결과를 필수로, 부동소수는 진단으로 다룬다.
- 보류 뒤 새 관측을 요청하는 고리(재확장이 실제로 새 정보를 얻는 경우)는 이번 범위가 아니다. 이번 결과가 그 실험의 필요 여부를 정한다.
- 인간의 직관·"쎄한 느낌", LLM 내부, 생물학에 대한 주장이 아니다. 설계·구현·실행·검산은 한 작성자(AI 연구 보조)의 한 세션 작업이며 blind 토론·별도 Judge는 없다.
